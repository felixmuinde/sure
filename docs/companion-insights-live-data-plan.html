Context

The Insights tab (InsightsPreviewScreen) currently shows hardcoded "Coming Soon" placeholders with fake static data. We're wiring it to live Chancen student ISA data stored in a Metabase warehouse.

Data Flow

Flutter app (InsightsPreviewScreen)
on init → fetches API key from AuthProvider
↓ GET /api/v1/my_account
X-Api-Key header
Rails: Api::V1::MyAccountController
reads Setting.metabase_* config
↓ POST /api/card/:id/query
Provider::MetabaseStudentAccount
filters rows by email, strips <TODO-MASK-PII> prefix
↑ StudentAccountData (8 fields)
JSON response → StudentAccount.fromJson → MyAccountProvider → UI
